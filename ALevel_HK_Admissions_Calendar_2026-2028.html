02 · 雅思：把6分输出提升到稳定表达

目标分三层：先核验目标专业与当年通道的最低要求；个人稳健目标为总7.5、写说至少6.5；进阶目标为写说7.0。听读保持现有优势即可，不要求为了总分8而长期增加负荷。若四项为8/7.5/6.5/6.5，按平均与取整规则总分可为7.0；若为8/7.5/6.5/7，平均7.25、总分7.5。具体考试可能波动，不能只补一项就保证总分。

  1. 2026.09诊断：先看真实写作及录音，区分观点不足、组织不清、语法错误、词汇搭配与口语停顿。只有分数不能诊断具体问题。
  2. 2026.10–2027.03建立反馈闭环：写作按任务回应/完成、衔接、词汇、语法四项评估；口语按流利连贯、词汇、语法、发音评估。每周写—评—改，每月由教师抽样校准。
  3. 2027.04–06考试保护：压缩至短表达和修订，学术考试后恢复诊断；不在考季集中冲雅思。
  4. 2027.07–08首选复考：两次模拟显示写说较稳定，再预约实际考位。考前复核Academic类型、学校认可形式与证件要求。
  5. 2027.09–10备用：仅在未满足语言要求、有效期不合适或写说仍影响学习交流时复考；满足要求且能力稳定后转技术表达。

AI可生成练习问题和指出可能的表达问题，不能把AI估分当作正式成绩；发音应结合实际音频及可靠教师反馈。科研英文答辩可以替代部分口语训练，但不能覆盖雅思生活类话题和全部考试技能。官方评分说明

03 · 学业：四科A*轨迹与AS结转

优先确认考试局、代码、组件与分阶段路径。9709已有2026年6月AS a、PUM91，不代表完整A-Level成绩，也不代表原始分91%。按Cambridge现行13个月规则，若希望使用该AS结果，应由考试官确认2027年6月或其他有效考试季的完整数学资格方案；不得默认放到2028年。该安排与2028大学入学可以并存。

每月看三类证据：概念解释、限时题表现、订正后迁移。Maths关注推导、计算和边界；FM关注先修与抽象迁移；Physics关注建模、单位、实验及误差；CS关注理论、伪代码和题意表达。AS阶段以a及学校掌握标准为目标，A*用于完整A-Level；不为各科编造统一PUM或原始分门槛。第五门名称与资格未确认，先由学校定位其课时和目标。

Cambridge官方结转说明。正式考试、报名与放榜时间按具体考试局和学校时间表录入。

04 · USACO：训练准备度与正式结果分开

每题流程：Constraints → Complexity Budget → Model → Algorithm → Proof → Counterexample → Code → Postmortem。错误标签：K知识、M建模、P证明/假设、C复杂度、I实现、E边界、T时间。完成题目后安排第2、7、21天重做；相同题只做一次复盘记录，不用重复题堆高数量。

2026秋季约40–50道高质量题是参考规模；有困难可减少。Promotion-Ready用至少3套未见题的独立稳定表现和失分原因判断，不设伪官方“固定晋级线”。Bronze不稳时回退基础；Silver已稳再逐步接触Gold内容，不把Platinum设为KPI。

目前核验到的USACO页面仍为2025–26回顾，不预设未来赛季12月一定有比赛。实际比赛时间、时长、资格及晋级规则按当季公告。正式比赛禁止AI、预写模板及赛中交流；同一要求用于完整模拟。官方规则。

05 · 科研：门槛先于日期，保留最小完整成果

主线：Dijkstra → A* → Weighted A* → Dynamic World → Repeated A* → 一种增量算法 → Benchmark与风险观察。LPA*可作为概念桥梁；D* Lite视基础与时间决定。高级时序风险与Minecraft/Baritone仅在已有成果稳定后进行，不要求申请前全部实现。

Gate必须能展示的证据
Concept / Manual非负边条件、松弛、暂定距离、finalized、优先队列重复项、确定性tie-break；可手算
Tests / Code学生先设计起终点同点、无路、边界、多解、权重差异等测试；独立实现核心算法
VerificationPathValidator独立验证；有已知解或独立最优性检查，不只验证路径能走通
Experiment7项真实metrics，场景/seed/配置/commit；指标口径固定、计时预热与重复策略明确
Defense解释正确性、复杂度、失败案例、与基线差异及个人贡献

先保持6-connected轴对齐移动；MovementModel可插拔；riskExposure与scalar cost独立。静态均匀代价可用BFS作最短距离交叉检查；后续带权图另选适当oracle。算法正确不代表更快，性能比较需相同场景、代价与事件序列；报告扩展节点数、运行时分布和失败样本，不预设增量算法一定优越。首次实验前固定指标口径：pathLength按移动步数还是顶点数、nodesGenerated是否含重复入队、nodesExpanded何时计数、riskExposure如何累计、planningTime的单位和计时边界；随后所有算法保持一致。

移动障碍后的快照重规划，不等同于有时间状态的危险预测。只有明确时间模型、等待/到达语义和验证条件后，才使用time-dependent hazard相关结论。受保护六算法仍由学生实现；导师提供问题、审查和局部提示。

07 · 专利与公开：只在出现技术成果时评估

专利不是月度KPI。本计划仅保留一个条件性决策：如果研究出现具体新机制、与现有技术的明确差异以及可重复的技术效果，再咨询适当的专利专业人士。拟申请时先确定公开策略，公开GitHub、视频、报告和演示材料均应纳入考虑。未完成相关评估前可使用私有仓库；没有专利计划时，不因想象中的专利机会阻碍合理展示。这里不提供专利性或授权结论。
